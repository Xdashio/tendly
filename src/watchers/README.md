# Watchers

Each watcher gets its own subdirectory here once it graduates from a spike
under `/spikes/` to a real implementation (see the Watcher contract in
[../../docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md#1-capture-layer--watchers)).

Planned: `x11/`, `wayland/`, `windows/`, `macos/`, `browser/`, `afk/`.
